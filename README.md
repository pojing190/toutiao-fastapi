# 头条后端（Toutiao Backend）

基于 **FastAPI** 构建的高性能异步新闻类应用后端，提供新闻资讯浏览、用户认证、收藏与阅读历史等完整能力，架构简洁、易于二次开发。

## ✨ 功能特性

- 🔐 **用户系统**：注册 / 登录 / 个人信息管理 / 修改密码
- 📰 **新闻模块**：分类浏览、列表分页、详情查看、浏览量统计、相关新闻推荐
- ⭐ **收藏功能**：新闻收藏 / 取消收藏 / 收藏列表 / 一键清空
- 🕘 **阅读历史**：浏览记录添加 / 删除 / 分页查看 / 一键清空
- 🚀 **性能优化**：Redis 缓存热点数据，数据库索引加速查询

## 🛠️ 技术栈

| 类别 | 技术 |
| --- | --- |
| Web 框架 | FastAPI |
| 数据库 | MySQL + SQLAlchemy（异步 ORM，aiomysql 驱动） |
| 缓存 | Redis（redis.asyncio） |
| 认证 | Token 认证 + bcrypt 密码加密 |
| 数据校验 | Pydantic |
| 跨域 | CORS 中间件 |
